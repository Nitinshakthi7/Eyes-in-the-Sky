# Model weights

Model weights (`*.pth`) are **not** in git: they are generated by training and are 0.4 to 45 MB each, so we share them separately.

The trained weights used by the website are shared here: **link TBD**

Put the downloaded files in this `models/` folder. The website loads them from here and never needs internet. Names it looks for: `mobilenet_v2_full_frac1_seed0.pth`, `resnet18_full_frac1_seed0.pth`, `scratch_cnn_frac1_seed0.pth`.
