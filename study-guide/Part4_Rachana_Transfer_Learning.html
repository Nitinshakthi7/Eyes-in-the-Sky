Part 4 – Rachana: Transfer learning (Part C)

What my part is

Part C asks one question: does a CNN that has already learned from millions of ImageNet photos classify EuroSAT satellite patches better than the small CNN that Tejash trained from random numbers? I own three pieces. The first is build_transfer_model(name, freeze) in src/models.py, which loads ResNet-18 or MobileNetV2 with ImageNet weights, optionally freezes the pretrained layers, and swaps the last layer for 10 classes. The second is notebooks/03_transfer_learning.ipynb, which runs the four settings for seeds 0, 1 and 2, checks the results, and draws the plots. The third is the Part C report draft (report/part_c_transfer_learning_draft.md) together with the figures and the history JSON files the notebook writes. I did not write the training loop, the data loader or the results writer: those are shared code in src/train.py (Nitin) and src/dataset.py (Srivalli), and my notebook only calls them with the team settings. The four settings are two models times two modes: frozen (only the new head learns, learning rate 0.001) and full fine-tuning (every layer learns, learning rate 0.0001). Each setting runs for three seeds, giving 12 transfer runs, and they are compared with Tejash's 3-seed scratch CNN on the same test split. In short: full fine-tuning reaches about 98% test accuracy, frozen models reach about 87%, and the scratch CNN reaches 92.7%.

Definitions

Transfer learning. Reusing a model trained on one task as the starting point for a different task, instead of starting from random weights. We reuse ImageNet models for satellite land-use classification.

Pretraining. The first training run, done by someone else on a big dataset, that produces the starting weights. Our pretraining is ImageNet classification, done by the torchvision authors. We only download and load the result.

ImageNet and ImageNet-1K. A large photo dataset with 1,000 object classes (dogs, cars, cups). ImageNet-1K is the standard version with about 1.28 million training images. Its classes are not land-use classes, but its low-level image features are general.

Fine-tuning. Continuing to train a pretrained model on the new data, so that its weights move to fit the new task. In our project this is the "full" setting, where every layer is updated.

Frozen backbone. The pretrained part of the network (everything except the last layer) with its weights fixed. Its weights are not updated, so only the new last layer learns.

Feature extractor. The part of a network that turns an image into a vector of numbers (features). In the frozen setting the backbone is a fixed feature extractor: it gives 512 numbers for ResNet-18 and 1,280 numbers for MobileNetV2 per image.

Classifier head. The final layer(s) that turn the features into class scores. Here it is one linear layer that outputs 10 scores, one per EuroSAT class. When only the head is trained on fixed features, the method is also called a linear probe.

requires_grad. A flag on each PyTorch tensor (parameter). If it is True, autograd computes a gradient for it during backpropagation. If it is False, the tensor is treated as a constant. Setting it to False also saves compute and memory, because no graph is built for those layers.

Gradient and backpropagation. The gradient of the loss with respect to each weight tells us how to change it to reduce the loss. Backpropagation computes these gradients layer by layer from the output back to the input.

Learning rate. The size of each weight update step. Too large and training becomes unstable or forgets pretrained knowledge; too small and training is slow.

Adam. An optimiser that adapts the step size for each weight using running averages of its gradients. We use it with default settings and no weight decay.

Catastrophic forgetting. When a network is trained on a new task, it can overwrite the weights that held its old knowledge. Full fine-tuning with a large learning rate can destroy the useful ImageNet features, which is why we use a 10x smaller learning rate for it.

Residual connection (skip connection). A shortcut that adds a block's input to its output, y = F(x) + x. The shortcut gives gradients a direct path back through the network, so very deep networks train well.

ResNet-18. A 2015 CNN with 18 weighted layers (17 convolutions plus one final linear layer) arranged in four stages of residual blocks. It has about 11.7 million parameters with its original 1,000-class head.

Inverted residual. The MobileNetV2 block design. It first expands the number of channels with a 1x1 convolution, filters with a depth-wise convolution, and then projects back down to a narrow output. The skip connection links the narrow ends, which is the reverse of a classic residual block (wide, narrow, wide).

Depth-wise convolution. A convolution that filters each input channel separately, with one 3x3 filter per channel, instead of mixing all channels in each filter. It is cheap in parameters and computation.

Depthwise separable convolution. A depth-wise convolution followed by a 1x1 "pointwise" convolution that mixes channels. Together they replace a normal 3x3 convolution with far fewer weights and multiplications.

MobileNetV2. A 2018 CNN designed for phones and low compute. It stacks inverted residual blocks with depth-wise separable convolutions and has about 3.5 million parameters with its original 1,000-class head.

Parameter count. The number of numbers stored in a model's weights and biases. Total parameters count every tensor; trainable parameters count only those with requires_grad=True. We compute both with p.numel().

BatchNorm (batch normalisation). A layer that normalises each channel of its input using the mean and variance of the current mini-batch, then applies a learnable scale (gamma) and shift (beta).

Running statistics (running_mean, running_var). Buffers that BatchNorm keeps as a moving average of batch means and variances. They are used in evaluation mode instead of batch statistics. They are not nn.Parameter objects, so requires_grad=False does not stop them from updating.

model.train() and model.eval(). Mode switches. In train mode BatchNorm uses batch statistics and updates its running buffers, and Dropout is active. In eval mode BatchNorm uses the stored running statistics and Dropout is off.

ImageNet normalisation. Subtracting the ImageNet mean and dividing by the ImageNet standard deviation per colour channel, using the values (0.485, 0.456, 0.406) and (0.229, 0.224, 0.225). Pretrained weights expect inputs on this scale.

torchvision weights enum. The ResNet18_Weights.DEFAULT style objects in torchvision. DEFAULT names the recommended weight set for that model, and a weight set also knows its own preprocessing.

Dropout. A layer that randomly zeroes a fraction of activations during training, to reduce overfitting. MobileNetV2 has one at 0.2 in its head, and we keep it.

Epoch and batch size. One epoch is one full pass over the training images. The batch size is how many images go through the network at once. We use 20 epochs and batch size 64.

Best-epoch selection. We keep the weights from the epoch with the highest validation accuracy, not the last epoch. This is a form of early stopping that uses validation data only.

Train, validation and test split. The 70/15/15 split of the 27,000 images in data/splits.csv. Training fits the weights, validation chooses the best epoch, and the test set is scored once at the end.

Accuracy. The share of test images whose predicted class is correct.

Macro-F1. For each class, compute the F1 score (harmonic mean of precision and recall), then take the unweighted average over the 10 classes. It treats rare and common classes equally.

Seed. A number that fixes the random generator, so that initial head weights, data order and augmentation are repeatable. We use seeds 0, 1 and 2.

Mean and sample standard deviation (ddof=1). The mean is the average of the three seeds. The sample standard deviation divides the sum of squared differences by n-1 = 2 instead of n = 3, which corrects for estimating spread from a small sample. ddof is the "delta degrees of freedom" argument of NumPy and pandas.

Stride and pooling. Stride is how many pixels a convolution jumps each step. A stride of 2 halves the height and width. Global average pooling (AdaptiveAvgPool2d(1) in our scratch CNN, and built into both torchvision models) averages each feature map to one number.

Domain shift. The gap between the data a model was trained on (ImageNet ground-level photos at 224x224) and the data we use (top-down Sentinel-2 patches at 64x64).

Data efficiency. How accuracy changes when we train on a fraction of the training images. This is Nitin's study (notebook 05). I use only the rows already in results/metrics.csv for context.

Checkpoint (.pth file). A saved state_dict, the dictionary of all weights of a model. We save the best-epoch weights into models/ (not in git).

Linear layer (nn.Linear). A fully connected layer that computes W x + b. nn.Linear(512, 10) has 512 x 10 weights plus 10 biases, which is 5,130 parameters.

Logits and cross-entropy loss. The raw scores from the last layer. CrossEntropyLoss applies softmax internally and compares the probabilities with the true class.

def build_transfer_model(name: str, freeze: bool = True):
    """Build a pretrained ImageNet model adapted for 10 EuroSAT classes.

    name:   'resnet18' or 'mobilenet_v2'
    freeze: True keeps the backbone fixed so only the new last layer trains;
            False lets all layers fine-tune.
    """
    if name == "resnet18":
        model = models.resnet18(weights=models.ResNet18_Weights.DEFAULT)
    elif name == "mobilenet_v2":
        model = models.mobilenet_v2(weights=models.MobileNet_V2_Weights.DEFAULT)
    else:
        raise ValueError(f"Unsupported transfer model {name!r}; expected 'resnet18' or 'mobilenet_v2'")

    if freeze:
        # Freeze all pretrained weights first.
        for param in model.parameters():
            param.requires_grad = False

    # Replace the 1000-class ImageNet head with a new 10-class linear layer.
    # A new nn.Linear has requires_grad=True by default, so it always learns.
    if name == "resnet18":
        model.fc = nn.Linear(model.fc.in_features, 10)
    elif name == "mobilenet_v2":
        model.classifier[1] = nn.Linear(model.classifier[1].in_features, 10)

    return model

2.3 Cell 4: seed-0 runs with the three-layer artifact guard

import math

seed0_runs = {}
history_path = FIGURES_DIR / 'transfer_seed0_histories.json'

existing_metrics_df = (
    pd.read_csv(METRICS_CSV)
    if METRICS_CSV.is_file() and METRICS_CSV.stat().st_size > 0
    else pd.DataFrame(columns=['model', 'fraction', 'seed', 'accuracy', 'macro_f1'])
)
saved_seed0_histories = {}
if history_path.is_file():
    if history_path.stat().st_size == 0:
        raise RuntimeError(f'Seed-0 history file is empty/corrupt: {history_path}')
    with open(history_path, 'r', encoding='utf-8') as f:
        saved_seed0_histories = json.load(f)

any_seed0_trained = False

for model_name in MODEL_NAMES:
    # 1. Check metrics CSV row for (model_name, FRACTION, INITIAL_SEED)
    row_matches = existing_metrics_df[
        (existing_metrics_df['model'] == model_name)
        & (pd.to_numeric(existing_metrics_df['fraction'], errors='coerce') == FRACTION)
        & (pd.to_numeric(existing_metrics_df['seed'], errors='coerce') == INITIAL_SEED)
    ]
    if len(row_matches) > 1:
        raise RuntimeError(
            f'Duplicate rows ({len(row_matches)}) in {METRICS_CSV} for '
            f'({model_name}, fraction={FRACTION}, seed={INITIAL_SEED}).'
        )
    has_csv = len(row_matches) == 1
    csv_acc, csv_f1 = None, None
    if has_csv:
        csv_acc = float(pd.to_numeric(row_matches['accuracy'].iloc[0], errors='coerce'))
        csv_f1 = float(pd.to_numeric(row_matches['macro_f1'].iloc[0], errors='coerce'))
        if not (
            math.isfinite(csv_acc)
            and math.isfinite(csv_f1)
            and 0.0 < csv_acc <= 1.0
            and 0.0 < csv_f1 <= 1.0
        ):
            raise RuntimeError(
                f'Invalid accuracy/macro_f1 in {METRICS_CSV} for '
                f'({model_name}, fraction={FRACTION}, seed={INITIAL_SEED}): acc={csv_acc}, f1={csv_f1}'
            )

    # 2. Check model checkpoint in models/
    ckpt_path = MODELS_DIR / f'{model_name}_frac{FRACTION:g}_seed{INITIAL_SEED}.pth'
    if ckpt_path.exists() and ckpt_path.stat().st_size == 0:
        raise RuntimeError(f'Checkpoint file is empty (0 bytes): {ckpt_path}')
    has_ckpt = ckpt_path.is_file() and ckpt_path.stat().st_size > 0

    # 3. Check seed-0 training history in transfer_seed0_histories.json
    has_hist = model_name in saved_seed0_histories
    if has_hist:
        entry = saved_seed0_histories[model_name]
        required_keys = {'best_epoch', 'val_accuracy', 'accuracy', 'macro_f1', 'seconds_per_epoch', 'history'}
        if not isinstance(entry, dict) or not required_keys.issubset(entry.keys()):
            raise RuntimeError(
                f'Invalid or incomplete history entry for {model_name} in {history_path}.'
            )
        hist = entry['history']
        for hkey in ('train_loss', 'train_accuracy', 'val_loss', 'val_accuracy'):
            vals = hist.get(hkey, []) if isinstance(hist, dict) else []
            if len(vals) != MAX_EPOCHS or not all(math.isfinite(float(v)) for v in vals):
                raise RuntimeError(
                    f'Invalid {hkey} history for {model_name} in {history_path} '
                    f'(expected {MAX_EPOCHS} finite epoch values).'
                )
        if has_csv and not (
            math.isclose(float(entry['accuracy']), csv_acc, abs_tol=1e-6)
            and math.isclose(float(entry['macro_f1']), csv_f1, abs_tol=1e-6)
        ):
            raise RuntimeError(
                f'Metric mismatch between {METRICS_CSV} and {history_path} for '
                f'({model_name}, fraction={FRACTION}, seed={INITIAL_SEED}).'
            )

    if has_csv and has_ckpt and has_hist:
        entry = saved_seed0_histories[model_name]
        seed0_runs[model_name] = {
            'model': model_name,
            'fraction': FRACTION,
            'seed': INITIAL_SEED,
            'best_epoch': int(entry['best_epoch']),
            'val_accuracy': float(entry['val_accuracy']),
            'accuracy': float(entry['accuracy']),
            'macro_f1': float(entry['macro_f1']),
            'seconds_per_epoch': float(entry['seconds_per_epoch']),
            'history': entry['history'],
        }
        print(
            f'Skip {model_name} (fraction={FRACTION}, seed={INITIAL_SEED}): '
            f'verified in {METRICS_CSV.name}, {ckpt_path.name}, and {history_path.name}'
        )
        continue

    if has_csv or has_ckpt or has_hist:
        raise RuntimeError(
            f'Inconsistent artifacts for ({model_name}, fraction={FRACTION}, seed={INITIAL_SEED}): '
            f'metrics_csv={has_csv}, checkpoint={has_ckpt} ({ckpt_path.name}), '
            f'seed0_history={has_hist} ({history_path.name}). Refusing to overwrite partial results.'
        )

    print('=' * 72)
    print(f'Starting {model_name} (fraction={FRACTION}, seed={INITIAL_SEED}, epochs={MAX_EPOCHS})')
    print('=' * 72)
    result = train(model_name, fraction=FRACTION, seed=INITIAL_SEED, epochs=MAX_EPOCHS)
    seed0_runs[model_name] = result
    any_seed0_trained = True
    existing_metrics_df = pd.read_csv(METRICS_CSV)
    print(
        f"Summary -> {model_name} | best val epoch: {result['best_epoch']} "
        f"| best val acc: {result['val_accuracy']:.4f} "
        f"| test acc: {result['accuracy']:.4f} "
        f"| test macro-F1: {result['macro_f1']:.4f} "
        f"| {result['seconds_per_epoch']:.1f} s/epoch\n"
    )

if any_seed0_trained or not history_path.is_file():
    with open(history_path, 'w', encoding='utf-8') as f:
        json.dump(
            {
                name: {
                    'best_epoch': res['best_epoch'],
                    'val_accuracy': res['val_accuracy'],
                    'accuracy': res['accuracy'],
                    'macro_f1': res['macro_f1'],
                    'seconds_per_epoch': res['seconds_per_epoch'],
                    'history': res['history'],
                }
                for name, res in seed0_runs.items()
            },
            f,
            indent=2,
        )
    print('Saved seed 0 histories to', history_path)
else:
    print('All seed 0 runs already complete and verified; preserved existing', history_path)

3. Architecture of the two models

ResNet-18. The network starts with a 7x7 convolution with stride 2 (64 filters), batch normalisation, ReLU and a 3x3 max-pool with stride 2. Four stages follow, with 2, 2, 2 and 2 basic blocks and 64, 128, 256 and 512 channels. A basic block is two 3x3 convolutions, each followed by batch normalisation, with a skip connection that adds the block input to its output. When the stage halves the image size or doubles the channels, the shortcut uses a 1x1 convolution to match the shapes. The skip connections matter because the gradient of y = F(x) + x with respect to x always contains a direct term of 1, so the learning signal reaches early layers even in a deep network. This is why ResNet can be trained deeper without the accuracy falling. The network ends with global average pooling (512 numbers per image) and the fully connected layer.

MobileNetV2. The first layer is a 3x3 convolution with stride 2 (32 channels). It is followed by 17 inverted residual blocks, a 1x1 convolution to 1,280 channels, global average pooling and a classifier. Each inverted residual block expands the channels with a 1x1 convolution (usually by a factor of 6), filters them with a 3x3 depth-wise convolution, and projects them back to a narrow layer with a 1x1 convolution that has no activation (the "linear bottleneck"). The skip connection is used only when the stride is 1 and the input and output widths match. The network uses depthwise separable convolutions because they are much cheaper. A normal 3x3 convolution from 128 to 128 channels needs 128 x 128 x 9 = 147,456 weights. Its depthwise separable version needs 128 x 9 = 1,152 weights for the depthwise step plus 128 x 128 = 16,384 for the pointwise step, a total of 17,536, which is about 8.4 times fewer. That saving is the reason MobileNetV2 has 2.24 million parameters against ResNet-18's 11.18 million.

Parameter counts and how the head was replaced. The counts below are the numbers printed by cell 2 and stored in the notebook output. The original torchvision models (with 1,000 ImageNet outputs) have 11,689,512 parameters for ResNet-18 and 3,504,872 for MobileNetV2. Our replacement subtracts the old last layer and adds the new one:

Model Original head Our head Total parameters now Trainable (frozen) Trainable (full)
ResNet-18 fc: Linear(512, 1000) = 513,000 fc: Linear(512, 10) = 5,130 11,689,512 - 513,000 + 5,130 = 11,181,642 5,130 (0.05% of total) 11,181,642
MobileNetV2 classifier[1]: Linear(1280, 1000) = 1,281,000 classifier[1]: Linear(1280, 10) = 12,810 3,504,872 - 1,281,000 + 12,810 = 2,236,682 12,810 (0.57% of total) 2,236,682

The arithmetic matches the printed numbers exactly, which is a useful check that the right layer was replaced. The in_features of the old layer (512 and 1,280) are used for the new one, so the feature sizes line up.

4. The four settings and why the learning rates differ

Setting Backbone trainable? Learning rate Trainable parameters What learns
resnet18_frozen No 0.001 5,130 Only the new 10-class head
resnet18_full Yes 0.0001 11,181,642 Every layer
mobilenet_v2_frozen No 0.001 12,810 Only the new 10-class head
mobilenet_v2_full Yes 0.0001 2,236,682 Every layer

The head starts from random numbers, so it needs larger steps to learn quickly; 0.001 (Adam's default value, and the team's setting for the new layer) is a reasonable choice. Full fine-tuning starts from good pretrained weights. A step of 0.001 applied to every layer would move those weights far from their useful values (catastrophic forgetting), so we use 0.0001, ten times smaller. These values come from the team defaults in build_model (1e-3 if freeze else 1e-4). I did not run a learning-rate search, and I did not find a record of one, so the values are defaults and not tuned results.

The caveat. Frozen and full differ in two ways at once: which layers learn, and the learning rate. So the difference between resnet18_frozen and resnet18_full is the combined effect of both changes. We cannot say how much of the 11-point gain is due to unfreezing alone. A clean test would run frozen at 0.0001 and full at 0.001 as well, or sweep the learning rate for each setting. These runs were not done, and the report should say so.

Other settings were held fixed for all four: batch size 64, Adam with foreach=False, 20 epochs maximum, best-epoch selection on validation accuracy, the same 70/15/15 split and the same augmentation (random 90-degree turns and flips, applied to training images only).

What frozen mode still changes. In train.py the whole model is set to model.train() every epoch. For frozen models, the BatchNorm layers in the backbone therefore still normalise with batch statistics and update their running_mean and running_var buffers. Their learnable scale and shift are frozen, but the normalisation itself is not. So the frozen backbone is not perfectly fixed, and its features change a little during training. This is a real detail and the report mentions it.

Speed. Frozen runs are faster per epoch because autograd builds no graph through the backbone. On seed 0 the seconds per epoch were 3.19 (ResNet-18 frozen), 7.88 (ResNet-18 full), 5.36 (MobileNetV2 frozen) and 14.96 (MobileNetV2 full). MobileNetV2 has fewer parameters but is slower to train on this GPU, because depth-wise convolutions use the GPU less efficiently. The timings are wall-clock on a laptop that also had a display-driver reset in one batch, so they are noisy and should not be used as a fair efficiency claim.

6. Why ImageNet features help on satellite images (and the limits)

Why they help. Early convolution layers in CNNs learn simple detectors: edges, corners, colour contrasts and repeated textures. These detectors are not specific to ground photos. A field boundary, a forest edge, a road line and a building edge all look like edges and texture to a first-layer filter. So even a frozen first stage gives useful input to the rest of the network, and fine-tuning adds the task-specific layers. Starting from pretrained weights also makes training converge faster and more stably than starting from random weights, which is visible in the seed-0 curves: the full models reach 95% validation accuracy within 2 to 3 epochs. The data-efficiency rows show the practical effect: with 5% of the training data, the pretrained model is about 17 pp more accurate than the scratch CNN.

Why frozen features are not enough here. The frozen models learn a single linear layer on top of features from ImageNet objects. Their deeper layers encode object parts (wheels, eyes, windows of buildings) at 224 by 224 scale. EuroSAT patches are 64 by 64 pixels of top-down Sentinel-2 imagery. A 64-pixel input is reduced by a factor of 32 in ResNet-18 and MobileNetV2, so the last feature map is only 2 by 2. The deep features therefore see very little spatial structure, which is one reason a linear probe on them underperforms the scratch CNN. Fine-tuning lets the deeper filters adapt to overhead texture.

Limits of the transfer argument.

  1. Scale and resolution. We feed 64 by 64 images directly, without resizing to 224. The ImageNet models were trained at a larger scale, so the object sizes they expect are not present in our patches. Upsampling to 224 was not tested, and it would cost about 12 times more compute per image.
  2. Bands. EuroSAT RGB uses only the three visible Sentinel-2 bands. ImageNet has no infrared or short-wave bands, and vegetation and water are often easier to separate with near-infrared. The Part C models therefore see less information than the full 13-band dataset could provide.
  3. Normalisation. train.py applies the ImageNet mean and standard deviation to the satellite images. These statistics describe photos, not satellite reflectance. The network still works because the normalised values are in a reasonable range, but the mismatch is not tuned.
  4. Data split and seeds. One fixed 70/15/15 split and three seeds show stable results (sample SD 0.12 to 0.45 pp), but they do not measure variation across different splits or across different random patches.
  5. Frozen vs full confounding. See section 4: the learning rate and the trainable layers change together, so the size of the gain from unfreezing is not isolated.
  6. BatchNorm in frozen mode. The running statistics of the frozen backbone keep updating on EuroSAT batches (section 4), so "frozen" does not mean fixed in every respect.
  7. Log-recovered histories. Seeds 1 and 2 have 4-decimal losses in the history JSON. The test scores and checkpoints are exact, so the numbers in the table are not affected.

Reproducibility notes from the code. Seeds fix the head initialisation, the batch order and the augmentation. The GPU augmentation is a different code path from the CPU loader used in Part B; Nitin's log reports his own reproduction of the scratch baseline as 92.79% against Tejash's 92.72%, and attributes the difference to the augmentation draws. I did not re-run that check, so I only quote the number.
